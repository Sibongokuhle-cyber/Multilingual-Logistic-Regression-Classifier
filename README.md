# Multilingual-Logistic-Regression-Classifier
Multinomial logistic regression (softmax) model for classifying news articles in English and isiXhosa across 7 categories. Compares TF-IDF, Bag-of-Words, and Binary features with L1/L2 regularization.  Tech: PyTorch, scikit-learn, NLP, Logistic Regression, TF-IDF. Open the SBYSIB014 gzip file for the code and detailed report.
